A free, mobile-first interactive birthday website (blue theme).

## How to open
Just open index.html in any browser (Chrome/Safari on phone is perfect).
Or use VS Code Live Server.

## Put it online for free
1. Create a GitHub repository
2. Upload the whole folder (index.html, style.css, script.js, assets/)
3. Go to Settings → Pages → set source to main branch
4. Your site will be live in 1–2 minutes

No paid hosting needed.

## Pages flow
Lock → Welcome → Question → Birthday → Gallery → Letter → Poem → Hug
